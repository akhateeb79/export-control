ARCHITECTURE CORRECTION (apply before writing any migration):
PostgreSQL requires the partition key to be part of the primary key on partitioned tables.
Apply these corrections to the DDL:
- audit_events: PRIMARY KEY (id, occurred_at) — partitioned by RANGE (occurred_at) monthly
- vendor_access_log: PRIMARY KEY (id, accessed_at) — partitioned by RANGE (accessed_at) monthly
All other DDL remains verbatim from docs/05-technical-architecture.md.
